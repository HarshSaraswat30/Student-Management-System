# 🎓 Student Management System

A simple and user-friendly **Student Management System** developed in Python.  
This project is designed to manage student records efficiently using basic Python concepts.

## 🚀 Features

- ➕ Add Student
- 📋 Display Student Records
- 🔍 Search Student
- ✏️ Update Student Details
- 🗑️ Delete Student
- 💾 Store and manage student data
- ❌ Exit the application

## 🛠️ Technologies Used

- Python 3
- File Handling
- Functions
- Conditional Statements
- Loops
- Lists / Dictionaries
- Exception Handling
